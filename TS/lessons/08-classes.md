# Урок №8. Классы и основы ООП в TypeScript

Статус: **не завершён**.

## Цель урока

После урока нужно понимать разницу между классом и объектом, уметь создавать конструкторы и методы, использовать `this`, управлять доступом к данным и реализовывать интерфейсы.

## 1. Класс и объект

Класс — описание данных и поведения будущих объектов. Объект — конкретный экземпляр, созданный через `new`.

~~~ts
class Car {
    brand: string;
    speed: number;
}

const firstCar = new Car();
const secondCar = new Car();
~~~

`Car` — класс, а `firstCar` и `secondCar` — два независимых объекта.

## 2. Состав класса

~~~ts
class Car {
    brand: string;
    speed: number;

    constructor(brand: string) {
        this.brand = brand;
        this.speed = 0;
    }

    accelerate(amount: number): void {
        this.speed += amount;
    }

    getSpeed(): number {
        return this.speed;
    }
}
~~~

- `brand` и `speed` — поля;
- `constructor` — первоначальная настройка объекта;
- `accelerate` и `getSpeed` — методы.

## 3. Как работает `new`

При выполнении `new Car("BMW")` создаётся объект, вызывается конструктор, параметры получают аргументы, `this` указывает на создаваемый объект, а готовый объект возвращается вызывающему коду.

## 4. Что означает `this`

`this` — текущий объект, для которого вызван конструктор или метод.

~~~ts
const bmw = new Car("BMW");
const audi = new Car("Audi");

bmw.accelerate(50);
audi.accelerate(20);
~~~

В первом вызове `this` указывает на `bmw`, во втором — на `audi`.

Распространённая ошибка:

~~~ts
constructor(brand: string) {
    brand = brand;
}
~~~

Параметр присваивается самому себе. Для заполнения поля нужно обращаться к полю текущего объекта через `this`.

## 5. Начальные значения

Поле можно заполнить при объявлении:

~~~ts
class Player {
    level: number = 1;
}
~~~

Либо получить значение через конструктор. Если поле не имеет начального значения, TypeScript в строгом режиме требует заполнить его в конструкторе.

## 6. Методы

Метод — функция внутри класса. Слово `function` перед методом не пишется.

~~~ts
class Counter {
    value: number = 0;

    increase(): void {
        this.value++;
    }

    getValue(): number {
        return this.value;
    }
}
~~~

Методы могут принимать параметры и возвращать значения, как обычные функции.

## 7. Инкапсуляция и модификаторы доступа

| Модификатор | Внутри класса | Снаружи | В наследнике |
|---|---:|---:|---:|
| `public` | да | да | да |
| `private` | да | нет | нет |
| `protected` | да | нет | да |

`public` установлен по умолчанию. `private` закрывает данные от прямого изменения снаружи. `protected` дополнительно разрешает доступ наследникам.

~~~ts
class Player {
    private health: number = 100;

    takeDamage(damage: number): void {
        if (damage > 0) {
            this.health = Math.max(0, this.health - damage);
        }
    }

    getHealth(): number {
        return this.health;
    }
}
~~~

Объект не может напрямую записать отрицательное здоровье. Изменение проходит через метод с проверкой.

## 8. `readonly`

`readonly` разрешает установить поле при объявлении или в конструкторе, но запрещает менять его после создания объекта.

~~~ts
class User {
    readonly id: number;
    nickname: string;

    constructor(id: number, nickname: string) {
        this.id = id;
        this.nickname = nickname;
    }
}
~~~

- `const` запрещает присвоить переменной другой объект;
- `readonly` запрещает изменить конкретное поле;
- `private` запрещает использовать поле за пределами класса.

## 9. Короткая запись конструктора

~~~ts
class Game {
    constructor(
        public title: string,
        private price: number,
        readonly id: number
    ) {}
}
~~~

Модификатор возле параметра конструктора одновременно объявляет поле и записывает в него аргумент. Сначала следует уверенно освоить полную запись конструктора.

## 10. Геттеры и сеттеры

Геттер позволяет читать закрытое поле как свойство, сеттер — контролировать его изменение.

~~~ts
class Profile {
    private _age: number = 18;

    get age(): number {
        return this._age;
    }

    set age(value: number) {
        if (value >= 0) {
            this._age = value;
        }
    }
}
~~~

Геттер используется без круглых скобок: `profile.age`. На первых задачах допустимо использовать более явные методы вида `getAge()`.

## 11. Объекты и ссылки

Каждый вызов `new` создаёт отдельный объект. Простое присваивание копирует ссылку:

~~~ts
const first = new Counter();
const second = first;

second.value = 100;
console.log(first.value); // 100
~~~

Обе переменные указывают на один объект.

## 12. `interface` и `implements`

Интерфейс задаёт требования, а класс предоставляет реализацию:

~~~ts
interface Describable {
    getDescription(): string;
}

class Book implements Describable {
    constructor(public title: string) {}

    getDescription(): string {
        return `Книга: ${this.title}`;
    }
}
~~~

`implements` не копирует готовый код. TypeScript только проверяет соответствие класса интерфейсу.

## 13. Как проектировать класс

Перед написанием кода ответь:

1. Какую сущность описывает класс?
2. Какие данные она хранит?
3. Какие действия выполняет?
4. Какие поля нельзя изменять напрямую?

После этого записываются поля, конструктор, методы изменения и методы чтения состояния.

Создай класс `Player`: `readonly id`, публичный `nickname`, приватный `level`, конструктор, метод повышения уровня и метод получения уровня.

### Задача №2. Банковский счёт

Создай `BankAccount` с `readonly accountId`, приватным балансом и методами `deposit`, `withdraw`, `getBalance`. Нельзя принимать отрицательные суммы или снимать больше текущего баланса. Методы изменения возвращают `boolean`.

### Задача №3. Товар

Создай интерфейс `Priceable` с методом `getFinalPrice()` и класс `Product`, который его реализует. Проверь товар стоимостью `2500` со скидкой `20%`; результат — `2000`.

### Задача №4. Исправление класса

Исправь ошибки и возле каждой оставь комментарий:

~~~ts
class User {
    readonly id: number;
    private password: string;

    constructor(id: number, password: string) {
        id = id;
        password = password;
    }

    getPassword(): number {
        return this.password;
    }
}

const user = new User(1, "secret");

user.id = 2;
console.log(user.password);
~~~

Не делай `password` публичным ради исправления.
